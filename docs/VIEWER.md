# Viewer 接続ガイド

この Colab ノートブックでは、学習済みモデルを表示するために2つの方法を提供しています。

## 1. 埋め込みウィジェット (推奨)

**"5. Start Viewer"** をクリックすると、Colab の出力セル内にインタラクティブなビューアが表示されます。
これには、IFrame 内で実行される [antimatter15/splat](https://github.com/antimatter15/splat) を使用しています。

- **メリット**: 設定不要で、すぐに使用できます。
- **デメリット**: パフォーマンスはブラウザと Colab プロキシへのインターネット接続に依存します。

## 2. Tailscale 経由のローカルブラウザ

ノートブックで **Tailscale** を有効にしている場合、ローカルマシンのブラウザから直接ビューアにアクセスできます。これにより、より良いパフォーマンスが得られ、別のタブでフルスクリーン表示が可能になります。

### セットアップ
1.  コントローラー(GUI)で **"Connect Tailscale (ssh)"** にチェックを入れます。
2.  Tailscale で認証を行います (ログにリンクが表示されます)。
3.  ローカルマシンも同じ Tailscale ネットワークに接続されていることを確認してください。

### アクセス方法
ビューアが起動したら、ローカルブラウザで以下の URL を開いてください:

```
http://colab:8000/
```

*(スクリプトの設定通り、Colab インスタンスのホスト名が `colab` に設定されていることを前提としています)*

## ファイル選択について

今回のアップデートで、表示するファイルを柔軟に選択できるようになりました。

### A. インスタンス上のファイルを表示
GUIに追加された **"Viewer Config"** セクションを使用します。
1. **"📂"** ボタンを押して、Colab インスタンス内の任意の `.ply` ファイルを選択します。
2. **"5. Start Viewer"** を押すと、そのファイルが読み込まれます。
   - ※ 指定がない場合は、`Output Path` にある最新の学習済みモデル (`point_cloud.ply`) が自動的に選択されます。

### B. ローカルPCのファイルを表示 (GPU不要)
ローカルPCにある `.ply` ファイルを表示したい場合は、以下の手順で行います。
1. **"Viewer File"** 欄を空欄にします (または無効なパス)。
2. **"5. Start Viewer"** を押すと、ファイルが指定されていない状態でビューアが起動します (またはデフォルトのデモなど)。
3. **ローカルPC上の `.ply` ファイルを、ビューアの画面内にドラッグ＆ドロップ** します。
   - ブラウザの機能により、ローカルファイルが読み込まれ、即座に表示されます。Colabへのアップロードは不要です。

## トラブルシューティング

- **画面が真っ暗になる?**: ローカルブラウザが WebGL をサポートしているか確認してください。
- **接続が拒否される?**:
    - 両端で Tailscale が接続されているか確認してください (`tailscale status`)。
    - Colab のログで、ビューアのプロセスが実際に実行されているか確認してください。
- **パフォーマンス**: ビューアはローカルブラウザ上 (WebGL を使用) でレンダリングされます。Colab インスタンスは静的ファイル (`.ply` ファイルとビューアのコード) を配信するだけです。モデルが大きい場合、ダウンロードに時間がかかることがあります。
